    quaternion_to_rotation_matrix ¶

    quaternion_to_rotation_matrix(q)

    Quaternion to rotation tensor R.

    Computes the rotation tensor (Eq. 348):

    R = q0^2 E - qbar^T qbar E + 2 qbar qbar^T + 2 q0 Q

    For a quaternion of frame B wrt frame W (q_BW), this is R_BW, mapping body-frame vector components to world-frame components:

    x_W = R_BW @ x_B

    The transformation matrix (world -> body) is its transpose (Eq. 214/350):

    T_BW = R_BW.T,  x_B = T_BW @ x_W

    Do not confuse the two: R != T.

    euler321_to_rotation_matrix(euler)

    Convert 3-2-1 Euler angles to rotation tensor R.

    Returns R (NOT the transformation matrix T):

    x_W = R_BW @ x_B,  T_BW = R_BW.T
    Input

    [roll, pitch, yaw]

    Reference: [1], Eq. (205), Eq. (214)

    Eq. (205) gives T. Eq. (214) gives R = T^T for the same rotation.

    rotation_matrix_jacobian(q)

    Jacobian of the normalized-quaternion rotation tensor.

    Computes:

    dR(q / ||q||) / dq

    R is the rotation tensor of Eq. (348), as computed by quaternion_to_rotation_matrix (NOT the transformation matrix T = R.T).

    Shape:

    (4, 3, 3)
    Notes¶

    The normalization Jacobian and the chain-rule combination have no direct numbered equation in the reference.

    wrap_to_pi ¶

    wrap_to_pi(angles, period=TWO_PI)

    Fold angle values into the half-open interval [-period/2, +period/2).

    This is the inverse of :func:unwrap_angles for a single value, and is useful for publishing or storing angles that must stay in a familiar bounded range.

    Parameters¶

    angles: 1D array of angle values.

    period

    Length of one full turn in the unit of angles.

    Returns¶

    numpy.ndarray Wrapped values, with the same length as the input. Non-finite values are preserved as NaN.

    unwrap_angles ¶

    unwrap_angles(angles, period=TWO_PI)

    Reconstruct the continuous series behind a wrapped angle sequence.

    Each sample is replaced by the representative nearest to its predecessor, so a crossing of the wrap boundary continues smoothly: 179, -179 degrees becomes 179, 181 rather than jumping back.

    The whole series is unwrapped at once, so the result stays continuous as a consumer inspects different time windows; unwrapping each visible window independently would make the curve move when the window moves.

    Non-finite samples are handled by unwrapping each contiguous finite run separately, leaving the non-finite samples untouched. This matters because unwrapping is cumulative: without segmentation, one NaN would corrupt every later value.

    After unwrapping, values drift outside the bounded range, growing by one full turn per revolution. That is the intended trade for continuity. Use :func:wrap_to_pi afterwards if the bounded range is needed.

    Parameters¶

    angles: 1D array of wrapped angle values.

    period

    Length of one full turn in the unit of angles.

    Returns¶

    numpy.ndarray Continuous angle values, with the same length as the input.

    Examples¶

    import numpy as np degrees = np.array([178.0, 179.0, -179.0, -178.0]) unwrap_angles(degrees, period=360.0) array([178., 179., 181., 182.])

    align_angles_to_reference ¶

    align_angles_to_reference(
    reference,
    values,
    reference_time=None,
    values_time=None,
    period=TWO_PI,
)

    Shift an angle series onto a reference angle series.

    Two series that are each internally continuous can still differ by a whole number of turns, because unwrapping is a per-series operation: an estimate that starts at 10 degrees and a ground truth that starts at -350 degrees describe the same rotation. Compared naively they look completely wrong.

    This function removes that ambiguity by adding the nearest multiple of one full turn to values so it lands on reference.

    The offset is the median of reference - values over the overlapping part of the session, rounded to a whole number of turns. The median makes it robust to individual outliers, and the rounding is what keeps the operation safe: only the arbitrary period * k ambiguity is removed, the genuine difference between the two series is never touched.

    Parameters¶

    reference: 1D reference series, typically the estimate.

    values

    1D series to be shifted onto the reference. Assumed to be continuous already, e.g. after :func:unwrap_angles.

    reference_time

    Optional 1D timestamps matching reference.

    values_time

    Optional 1D timestamps matching values. Both time arguments must be given together; when they are, values is interpolated onto the reference timestamps inside their overlapping span.

    period

    Length of one full turn in the unit of the series.

    Returns¶

    numpy.ndarray values shifted by a whole number of turns, unchanged when there is not enough data to estimate an offset.
