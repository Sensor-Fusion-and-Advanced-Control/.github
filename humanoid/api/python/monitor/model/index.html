    humanoid_monitor.state_estimation.model¶

    humanoid_monitor.state_estimation.model ¶

    Data model for the State Estimation Monitor.

    This module stores state-estimation history independently of:

    • ROS
    • Qt
    • plotting
    • visualization logic

    The controller writes data into this model. The GUI reads data from this model at its own refresh rate.

    StateEstimationModel ¶

    StateEstimationModel(history_limit_seconds=None)

    Central data store for the State Estimation Monitor.

    Stored data¶

    EvaluationState: - estimated RPY - estimated position - estimated velocity - estimated acceleration

    - optional ground-truth RPY
- optional ground-truth position
- optional ground-truth velocity
- optional ground-truth acceleration

- instantaneous errors
- running performance metrics
    StateEstimate
    • gyro bias
    • accelerometer bias
    Notes¶

    All orientation quantities are stored internally in radians.

    Timestamps are stored internally as raw ROS timestamps in seconds.

    Public read methods return time relative to the beginning of the current monitoring session.

    latest_time property ¶

    latest_time

    Latest relative session time.

    version property ¶

    version

    Model version.

    Changes whenever new data is appended or the model is reset.

    ground_truth_available property ¶

    ground_truth_available

    Latest ground-truth availability reported by evaluation.

    has_evaluation_data property ¶

    has_evaluation_data

    True if at least one EvaluationState sample exists.

    has_bias_data property ¶

    has_bias_data

    True if at least one bias sample exists.

    max_velocity_error=None,
    max_orientation_error_rad=None,
    max_acceleration_error=None,

    Append one EvaluationState sample.

    Parameters¶

    timestamp: ROS message timestamp in seconds.

    estimated_*: Estimated state vectors.

    ground_truth_available

    True when ground-truth fields are valid.

    ground_truth_*: Ground-truth state vectors. Required when ground_truth_available is True.

    error / performance values: Evaluation metrics already calculated by the state estimator evaluation subsystem.

    get_state_window ¶

    get_state_window(
    state_name, start_time=None, end_time=None
)

    Return estimated and ground-truth data for one vector state.

    Parameters¶

    state_name: One of: "rpy" "position" "velocity" "acceleration"

    start_time

    Relative session time in seconds.

    end_time

    Relative session time in seconds.

    Returns¶

    dict: { "estimate_time": ndarray, "estimate": ndarray shape (N, 3),

        "ground_truth_time": ndarray,
    "ground_truth": ndarray shape (M, 3),

    "ground_truth_available": bool,
}

    get_latest_performance ¶

    get_latest_performance(end_time=None)

    Return the most recent valid performance metrics.

    If end_time is supplied, return the latest metrics at or before that relative session time.

    This allows the Performance tab to follow the shared history slider later.

    get_time_bounds ¶

    get_time_bounds()

    Return the relative time range of the current session.

    Returns¶

    tuple: (start_time, end_time)

    The session always starts at 0.0.
