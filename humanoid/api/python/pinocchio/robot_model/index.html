    humanoid_pinocchio.robot_model¶

    humanoid_pinocchio.robot_model ¶

    RobotModel ¶

    RobotModel(
    description_package='humanoid_description',
    robot_name='max',
    urdf_path=None,
)

    Bases: KinematicsMixin, CentroidalMixin, DynamicsMixin, SnapshotMixin, VisualizerMixin

    Central Pinocchio model interface for the MAX humanoid robot.

    The robot is modeled as a floating-base system.

    Responsibilities: - load the robot URDF - build the Pinocchio model - create and own the Pinocchio Data object - store the current robot state (q, v, a) - provide joint/frame information - provide the common model interface used by other modules - display the robot in Gepetto viewer (:class:~.visualizer.VisualizerMixin)
