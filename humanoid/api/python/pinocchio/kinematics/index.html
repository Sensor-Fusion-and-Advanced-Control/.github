    humanoid_pinocchio.kinematics¶

    humanoid_pinocchio.kinematics ¶

    KinematicsMixin ¶

    Kinematic computations for the robot model.

    All public methods operate on the current state stored in RobotModel.

    Conventions¶

    Pose: 4x4 homogeneous transformation matrix.

    Spatial vectors

    [linear_x, linear_y, linear_z, angular_x, angular_y, angular_z]

    Jacobian

    Shape (6, nv).

    Default reference frame

    LOCAL_WORLD_ALIGNED

    inverse_kinematics ¶

    inverse_kinematics(
    frame_name,
    target,
    q0=None,
    task='position',
    active_joints=None,
    freeze_floating_base=True,
    max_iterations=500,
    position_tolerance=0.0001,
    orientation_tolerance=0.001,
    step_size=0.2,
    damping=1e-06,
    enforce_joint_limits=True,
)

    Solve iterative inverse kinematics for a robot frame.

    Parameters¶

    frame_name : str Target frame.

    target

    If task='position': 3D target position, 4x4 pose, or pin.SE3.

    If task='pose': 4x4 pose or pin.SE3.

    array_like, optional

    Initial configuration. Defaults to the current RobotModel q.

    {'position', 'pose'}

    Position-only or full SE(3) inverse kinematics.

    iterable of str, optional

    Joints allowed to move.

    By default, joints in the kinematic chain of the target frame are used, excluding the floating-base root joint.

    bool

    Keep root_joint fixed by default.

    int

    Maximum CLIK iterations.

    float

    Position convergence tolerance in meters.

    float

    Orientation convergence tolerance in radians.

    float

    Integration step size.

    float

    Damped least-squares regularization.

    bool

    Clamp scalar active joints to model position limits.

    Returns¶

    dict { 'q': solution configuration, 'success': bool, 'iterations': int, 'task': str, 'active_joints': list, 'position_error': float, 'orientation_error': float or None, }

    Notes¶

    This solver uses a dedicated Pinocchio Data object. RobotModel.q, v, a and the shared self.data are not modified.
